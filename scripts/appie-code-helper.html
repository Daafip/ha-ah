Appie login code helper

Paste whatever text contains the failed appie://login-exit?code=... redirect (or just the code itself) below. This runs entirely in your browser — nothing is sent anywhere.

This page can't catch the redirect automatically — why?

appie://login-exit?code=... is a custom URL scheme, not a web address. When your browser hits it, it hands off to whatever app is registered for appie:// at the OS level — no HTML page is ever loaded, so nothing hosted (including this page) can intercept that step. This page only helps with the last bit: turning whatever text you can get your hands on into a clean, copyable code.

If your browser doesn't show the failed URL anywhere (no error page, no address bar text), the most reliable way to get it on a phone is remote debugging from a computer over USB: chrome://inspect for Android Chrome, or Safari's Develop → [your iPhone] menu on macOS — both show the Network tab, where the failed request's Location header is the full appie://... URL, regardless of what the phone's screen shows.
